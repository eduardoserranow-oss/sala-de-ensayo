SOUNDGYM — STEM SETS PARA BALANCE MEMORY

Este paquete contiene 3 canciones procesadas como conjuntos de stems sincronizados.
Cada set incluye: full mix, drums, bass, music (guitars/melodys) y vocals.

IMPORTANTE
- No mezclar estos archivos con el manifest general de clips sueltos.
- Mantenerlos agrupados mediante stem-sets.json.
- Ruta recomendada en el repositorio:
  assets/sound-gym-stems/
- El juego Balance Memory debe cargar:
  assets/sound-gym-stems/stem-sets.json

Cada canción fue recortada con EL MISMO inicio y duración para todos sus stems, preservando sincronía.
Los segmentos son de 24 segundos y 192 kbps estéreo, suficientes para escoger fragmentos de 6 s durante las rondas.

Roles normalizados del juego:
- drums
- bass
- music (Guitars en ALEFU/Esto no se llama Amor; Melodys en Gimme dat Love)
- vocals

No reemplaza assets/sound-gym-audio/manifest.json. Es una biblioteca paralela diseñada para juegos que necesiten stems.
